# CV / Резюме

Единая структура резюме в двух языковых версиях. Оба файла имеют **одинаковый каркас**: совпадают состав, порядок и уровень заголовков, а также набор полей в каждой записи опыта.

- [cv-ru.md](./cv-ru.md) — Русская версия
- [cv-en.md](./cv-en.md) — English version

## Каркас документа

| # | Русская версия (cv-ru.md) | English version (cv-en.md) | Уровень |
|---|---|---|---|
| 1 | `# Александр Артамонов` | `# Alexander Artamonov` | H1 |
| 2 | `**Заголовок** — …` (одна строка) | `**Headline** — …` (одна строка) | plain |
| 3 | `## Контакты` | `## Contacts` | H2 |
| 4 | `## О себе` | `## Summary` | H2 |
| 5 | `## Локация и занятость` | `## Location & Availability` | H2 |
| 6 | `## Языки` | `## Languages` | H2 |
| 7 | `## Ключевые навыки` | `## Core Skills` | H2 |
| 8 | `## Опыт работы` | `## Experience` | H2 |
| 8.1 | `### Компания — Должность` | `### Company — Role` | H3 |
| 8.2 | `[ссылка на компанию]` | `[company link]` | plain |
| 8.3 | `**Период:** …` | `**Period:** …` | bold |
| 8.4 | абзац описания | description paragraph | plain |
| 8.5 | `**Достижения:**` + пункты списка | `**Achievements:**` + bullets | bold |
| 8.6 | `**Стек:** …` | `**Stack:** …` | bold |
| 9 | `## Образование` | `## Education` | H2 |
| 9.1 | `### ВУЗ` | `### University` | H3 |
| 9.2 | `**Период:** …` | `**Period:** …` | bold |
| 9.3 | `**Степень:** …` | `**Degree:** …` | bold |

> Раздел «Дополнительно» / «Additional» не используется — при необходимости добавляется последним в обоих файлах одновременно.
>
> В разделе «Образование» / «Education» может быть несколько записей — они идут в обратном хронологическом порядке (сначала вуз, затем колледж/техникум), каждая в едином формате `### Учреждение` + `**Период:**` + `**Степень:**`.
>
> Блок достижений — строка `**Достижения:**` / `**Achievements:**` и сразу под ней маркированный список из 2–6 пунктов. Располагается между абзацем описания и блоком `**Стек:**`. Каждый пункт — один измеримый результат (метрика, эффект, масштаб) в одну строку, без вложенных списков. Порядок и количество пунктов совпадают в обеих версиях.

## Правила синхронизации версий

1. **Один набор секций.** Любое изменение каркаса вносится в оба файла одновременно, порядок и уровень заголовков обязаны совпадать.
2. **Единая запись места работы.** Обязательные блоки идут в фиксированном порядке: `### Компания — Должность`, ссылка на компанию, `**Период:**`, описание, `**Стек:**`. Необязательный блок `**Достижения:**` добавляется между описанием и `**Стек:**` (см. правило 7) — либо сразу в оба файла, либо ни в один.
3. **Формат периода:** `<месяц год> — <месяц год | настоящее время> · <длительность> · <локация>` (месяцы словами на языке файла). Если месяцы неизвестны, допускается сокращённый вид `<год> — <год>` (тогда длительность не указывается, локация указывается как обычно).
4. **Пара имён компании:** `Лемана Тех (Leroy Merlin)` / `Leman Tech (Leroy Merlin)`; ссылка на компанию одинаковая в обоих файлах.
5. **Пара должностей:** `Backend-разработчик (ведущий) · Technical Lead` — RU-часть только в `cv-ru.md`, EN-часть только в `cv-en.md`.
6. **Единая цифра опыта:** «более 9 лет» / «9+ years». Значения в разделах «О себе» / «Summary» должны совпадать.
7. **Единый блок достижений.** Если у записи опыта есть блок `**Достижения:**` / `**Achievements:**`, он присутствует в обеих версиях с одинаковым числом пунктов и в одинаковом порядке; факты, метрики и цифры в пунктах идентичны, переводятся только формулировки. Пункты нумеруются обычным маркированным списком (`- `), без вложенности и выделений внутри строки.
8. **Единый состав стека:** списки `**Стек:**` / `**Stack:**` синхронизируются по смыслу; технологии указываются одинаково (например, `ClickHouse` присутствует в обоих файлах).
9. **Ссылки** — абсолютные URL, идентичные в обоих файлах.
10. **Только `docs/cv-*.md`** являются источником правды; профильные площадки (Хабр Карьера, LinkedIn) обновляются вручную из этих файлов.
11. **Раздел «Языки» / «Languages»** несёт одинаковый смысл в обеих версиях: `Русский — Родной` / `Russian — Native`, `Английский — B1 (средний уровень)` / `English — B1 (Limited Working Proficiency)`. В русской версии формулировки — только на русском языке (допускается лишь код уровня CEFR, например `B1`).

## Проверка паритета

```bash
grep -c '^#' docs/cv-en.md docs/cv-ru.md          # число заголовков должно совпадать
grep -n '^##' docs/cv-en.md docs/cv-ru.md         # порядок H2 должен совпадать 1:1
grep -c '^\*\*Достижения:\*\*' docs/cv-ru.md       # число блоков достижений должно совпадать
grep -c '^\*\*Achievements:\*\*' docs/cv-en.md
```
